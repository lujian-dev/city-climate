# 城市气候舒适度看板

用 2025 年全年逐日气象数据，比较 13 座中国城市的气候舒适程度。

## 它回答什么问题

「哪座城市的气候最舒服」——答案取决于你怎么定义「舒服」。

本项目把「舒适日」定义为：日均温在 12–28℃ 之间，且当天降水量不足 1 毫米。

## 数据来源

Open-Meteo 历史气象 API，逐日气温与降水，无需 API Key。

## 主要功能

- 计算每座城市的舒适天数、舒适占比、年均温、年降水、极端高温与严寒天数
- 舒适天数排行榜
- 多城市月均气温对比
- 完整指标表格

## 运行方式

    pip install -r requirements.txt
    streamlit run climate.py

## 一个发现

把舒适区间从 15–25℃ 放宽到 12–28℃ 后，三亚仍然第一（132 → 163 天），
但昆明从第 6 掉到并列第 11——它的舒适天数明明从 74 涨到了 102，
只是别的城市涨得更多。

**绝对值上涨，不等于相对位置改善。**

## 方法的迭代

最初用「日均温 15–25℃」判定舒适日。这个定义只看了温度，忽略了湿度——同样是 28℃，广州 84% 的湿度和乌鲁木齐 35% 的湿度，体感完全不同。

改用温湿指数（THI = T − 0.55 × (1 − RH) × (T − 14.4)）后，13 座城市的排名明显重排：

- 乌鲁木齐：75 天 → 132 天，接近翻倍
- 西安：66 天 → 94 天，从第 10 升到第 5
- 昆明：74 天 → 74 天，天数不变，排名从第 6 掉到第 12

昆明这个例子最说明问题：**它的舒适天数一天没变，排名却掉了六位。** 因为换指标不只是改变某座城市的分数，它改变了所有人的尺子。

结论：**任何「最舒服的城市」榜单，都取决于它用什么指标。看到排名，先问一句——它是怎么算的？**
